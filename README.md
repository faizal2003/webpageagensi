# Eschanyx

A responsive, dependency-free agency profile using the supplied logo.

Run `npm run dev` and open http://127.0.0.1:5173. You can also open `index.html` directly.

The project brief form downloads a text file locally. It does not send inquiries or collect information on a server. Connect a verified contact email or submission endpoint before using it for live leads.

Fonts load from Google Fonts with local sans-serif fallbacks. All artwork is CSS and the supplied logo is local.

Components include scroll reveals, animated service accordions, expandable process steps, service-specific brief shortcuts, and hover/focus feedback. Both artwork panels animate automatically with gentle floating and rotation, without mouse interactions or artwork controls. The header motion toggle remembers your preference locally; system reduced-motion settings disable decorative animation automatically. Page content stays visible without JavaScript.
